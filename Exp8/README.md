# Ex.No 08 – Creating and Executing Your First Container Using Docker

## Aim
Create and execute your first container using Docker.

## Files
- `main.py` — Python script executed inside the container.
- `Dockerfile` — builds the image from `python:latest` and runs `main.py`.
- `commands.sh` — Docker install, build, and run commands, plus a reference
  list of useful Docker commands.
- `output.txt` — build and run output.

## Result
Docker was installed, the image `python-test` was built from the `Dockerfile`,
and running the container printed `Docker is magic!` successfully.
